About me

Web, automation and AI — I build applications and systems that bring these areas together.

I’m a third-year Computer Science student. My focus is web development, scripting, and automation.

I fell in love with programming because code lets me turn ideas into real, working products. Today I build full-stack projects where the frontend and backend come together as one system.

What interests me most is automating routine processes. If something happens twice, I think about how to make it run by itself the third time. I actively use AI in this approach: on one hand as a workflow agent that runs multi-step processes automatically, and on the other as a development tool that speeds up writing code, debugging, and learning new technologies.
