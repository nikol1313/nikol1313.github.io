# nikol1313.github.io

Personal portfolio site of Nikusha Avsajanishvili, served with GitHub Pages.

Live at [nikushaavsajanishvili.com](https://nikushaavsajanishvili.com).

## Structure

- `index.html` – page markup
- `css/` – per-section stylesheets
- `script.js` – interactivity and translations
- `images/` – photos, logos and demo media
- `data/` – generated data (LeetCode count)
- `.github/workflows/` – scheduled automation
